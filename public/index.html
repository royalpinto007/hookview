    How hookview reads the chain Architecture + limits

    A local Node server reads confirmed account data from public Solana RPC. It decodes the mint's TransferHook extension, checks the configured program account, derives the optional extra-account PDA and decodes its Execute list. Each account has its own observation slot.

    Dynamic addresses need transfer-specific data and remain unresolved. Pointer authority is different from program upgrade authority, which is not inspected. Other token extensions and custom code may add behavior. See the official interface.
